# Cross-Network-Federated-Learning-Ghana-s-Interoperable-Telecom-Ecosystem-
MSc thesis code (KNUST): a Cross-Network Federated Learning (CNFL) framework that lets mobile money operators jointly train fraud detection models without sharing raw transaction data. Built on PaySim with non-IID operator partitions, SMOTE-ENN resampling, weighted FedAvg and SHAP explainability.
